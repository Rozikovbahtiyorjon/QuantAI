# Experimental (Frozen) Modules

Выделено в Фазе 0 аудита (2026-08-25).

## Что это

Модули, которые **не используются нигде, кроме собственных тестов**
(не импортируются ни ядром, ни точками входа). Перенесены из `src/`,
чтобы не мешать развитию рабочего контура. Код сохранён как есть,
импорты переписаны `src.*` → `experimental.src.*`.

## Статистика

- Перенесено: 53 модуля (`experimental/src/`) + 59 тестовых файлов (`experimental/tests/`)
- Осталось в `src/` (pinned): 29 модулей из «мёртвого» списка — их тесты
  покрывают одновременно и живой код (например, `champion_evaluator`,
  `strategy_bank`, `strategy_genome`, `order_flow_intelligence`)

## Как запускать архивную сюиту

```bash
pytest experimental/tests -q
```

- Для 29 модулей, оставшихся в `src/` (pinned), сгенерированы shim-файлы
  `experimental/src/<module>.py` — архивная сюита собирается полностью.
- `stale_test_ai_memory.py` — тест устаревшего API (`MEMORY_LAYERS`),
  переименован, чтобы не ломать коллекцию. Модуль `ai_memory`
  переписан на новый контракт (`ThreeTierMemory`) и ожидает новый тест.

## Правила

1. **Никаких новых фич в архиве.** Только чтение/удаление.
2. Возврат модуля в ядро — только через ревью: модуль подключается к
   пайплайну, его тест возвращается в `tests/`.
3. Приоритет для восстановления (по решению аудита):
   - `champion_evaluator`, `strategy_bank`, `strategy_tournament`*
     (*турнир пока pinned в `src/`) — фундамент Strategy Bank;
   - `market_regime_intelligence` — база режимного фильтра;
   - `fast_vector_backtester` — если понадобится векторная скорость.
4. Всё остальное — кандидаты на удаление после Фазы 3.
